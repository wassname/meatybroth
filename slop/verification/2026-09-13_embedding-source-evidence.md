## AWS Titan V2 documentation

Source: [Amazon Titan Text Embeddings model parameters](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-titan-embed-text.html), AWS documentation.

> The inputText parameter is required. The normalize and dimensions parameters are optional.
>
> dimensions – (optional) [...] accepted: 1024 (default), 512, 256.

Source: [Amazon Titan Text Embeddings models](https://docs.aws.amazon.com/bedrock/latest/userguide/titan-embedding-models.html), AWS documentation.

> The Amazon Titan Text Embedding v2 model (`amazon.titan-embed-text-v2:0`) can intake up to 8,192 tokens or 50,000 characters [...] Output vector size – 1,024 (default), 512, 256.

Source: [AWS Titan V2 launch post](https://aws.amazon.com/blogs/aws/amazon-titan-text-v2-now-available-in-amazon-bedrock-optimized-for-improving-rag/), AWS describing its own measurements.

> We measured the accuracy of the vectors generated by Amazon Titan Text Embeddings V2 and we observed that vectors with 512 dimensions keep approximately 99 percent of the accuracy provided by vectors with 1024 dimensions.

This is AWS's aggregate evaluation claim, not a Meaty Broth result.
